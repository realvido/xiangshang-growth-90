## GitHub Pages 发布

此包内的 index.html 等文件放在一个新建仓库的根目录，不要套一层dist文件夹。
在 Settings → Pages 中选择 Deploy from a branch，选择默认分支的 / (root)，保存。
等待GitHub给出实际发布网址后再打开。无需填写Custom domain，不修改原独立站域名。
如果账号的用户站点已绑定旧域名，项目站点可能继承；发布前需核对，不能假定一定使用github.io。

发布为公共网站时，课程代码可被访问；个人笔记和进度仍只保存在各访客自己的浏览器。
首次缓存完整后支持离线学习；外链仍需网络。原站进度需从旧站导出JSON，再在新站导入。

GitHub Pages可使用默认域名；它不等于对中国内地所有运营商的访问保证。
正式使用前需在iPhone关闭VPN、分别使用Wi-Fi和移动数据测试。

课程文件更新后需递增sw.js缓存版本。程序包已做子目录路径与离线加载自动检查。
